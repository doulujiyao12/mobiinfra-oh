# ClawMate WATCH 6 Pro

本模块是现有 ClawMate 应用的手表入口，仅面向 `wearable`。

录音库支持按日期浏览：点击顶部“全部日期”选择有录音的一天，或切回全部记录。点击“多选”勾选录音，也可全选当前显示的条目，再确认删除。切换日期会清空勾选；正在同步的录音会保留，删除仅作用于手表上的文件。

开发、运行配置、签名和发布流程见 [多端集成说明](../docs/WATCH_INTEGRATION.md)。原始手表实现来源为 ClawMate-Watch，MIT 许可见本目录 LICENSE，WebRTC 等第三方声明见 THIRD_PARTY_NOTICES.md。
