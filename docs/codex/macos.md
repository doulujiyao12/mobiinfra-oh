# macOS 连接指南

[返回下载与指南](README.md) · ClawMate Codex 1.1.11

在自己的电脑安装 ClawMate Codex 连接器，登录、选择项目，再用手机扫码。运行组件已经内置，无需另装 Node.js 或 npm。

> 适用于 Apple Silicon（M 系列）。当前应用未签名、未公证，请先核对 Release 中的 SHA256。

## 1. 安装连接器

下载 macOS ZIP 并解压，将 ClawMate Codex.app 移入「应用程序」。若系统阻止打开，确认来源和校验值后，在系统设置 → 隐私与安全性中查看允许打开的选项。无需关闭系统安全保护。

## 2. 登录 Codex 账号

在电脑「连接设置」点击「使用浏览器登录」，在官方登录页面完成授权。账号需具备 Codex 使用资格。OpenAI 登录凭据留在电脑，手机使用独立的设备凭据。

## 3. 选择允许操作的目录

点击「选择项目」，添加实际项目文件夹。保留「局域网 · 自动安全配对」，监听范围选择「允许局域网 / 远程设备访问」，保存设置。只添加你希望手机操作的项目。

## 4. 启动手机连接

点击「启动手机连接」，确认服务已启动。手机和电脑先连接同一个可互访的 Wi-Fi；异地连接请先按 Tailscale 教程组网。默认端口为 8787，以电脑实际显示为准。

## 5. 生成配对二维码

在电脑「手机配对」选择手机能访问的本机地址：同一 Wi-Fi 选局域网 IP，Tailscale 选 100 开头的 IP。点击「生成配对信息」，保持二维码页面打开。

## 6. 手机扫码或粘贴配对

手机打开 Codex → 创建连接 → 扫描二维码，核对电脑名称和地址后连接。也可导入电脑导出的配对文件，或粘贴完整配对信息；不要填写「连接保护」里的指纹。

## 7. 开始第一条任务

连接后选择项目，发送「概括这个项目的结构」。之后可在「我的连接」轻点电脑重连，右侧菜单可断开或删除连接。电脑端连接器需保持运行。

## 常见问题与注意事项

- 配对码 5 分钟内有效，只能使用一次。请粘贴完整配对信息或导入配对文件；证书指纹不是 token。不要公开配对码和文件。
- 新任务默认允许工作目录内修改，并在需要时请求批准。可在会话右上角设置改为只读分析；完全访问需要主动选择。
- 左上角菜单 → 电脑会话，可查看已授权项目的已有会话。实时共享需要原 Codex 后台在线且协议兼容；仅登录同一账号不会同步另一台电脑的历史。
- 连接超时先确认电脑在线、服务已启动、手机能访问所选地址，可信网络的防火墙允许该端口。跨网络请先完成 Tailscale 组网。IP 变化后，空闲时重启服务并重新配对。
- 窗口关闭时选择「隐藏窗口」可保留连接；选择「关闭应用」、休眠或关机会中断连接。升级前先结束任务并退出旧版，已有配置与配对数据会保留。
