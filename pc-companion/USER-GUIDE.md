# ClawMate Codex 电脑端

安装这一个程序即可从鸿蒙 ClawMate 使用电脑上的 Codex。运行组件已随程序内置，不需要安装 Node.js、npm、Git 或查找源代码。项目本身需要的编译器和依赖仍由项目决定。

[下载安装包与分平台步骤](../docs/codex/README.md) · [Windows](../docs/codex/windows.md) · [macOS](../docs/codex/macos.md) · [Linux CLI](../docs/codex/linux.md) · [Tailscale 组网教程](../docs/codex/tailscale.md)

## 桌面使用

1. Windows 运行安装向导；macOS 按芯片选择 Apple Silicon（arm64）或 Intel（x64）ZIP，解压后将应用移入“应用程序”；Linux 解压桌面便携包后打开 ClawMate Codex，无桌面环境请使用终端包。所有包均未签名、Mac 未公证。
2. 打开程序，在“连接设置”点击“使用浏览器登录”。在打开的官方页面登录自己的 Codex/ChatGPT 账号。没有浏览器的服务器可使用设备验证码登录。
3. 点击“选择项目”，先从本机 Codex 已有项目列表中搜索、选择，也可点击“浏览其他文件夹”。列表只读取本机项目与近期会话的目录信息，已删除、不可访问及包含连接凭据的根目录会过滤；发现和选择本身不会授权手机。添加后，保留“局域网 · 自动安全配对”，点击“保存设置”和“启动手机连接”。连接服务运行时需先停止服务，才能修改项目。
4. 确认手机和电脑网络可互访。如系统防火墙询问是否允许此程序接收局域网连接，按所使用的可信网络设置。
5. 在“手机配对”选择这台电脑的地址，点击“生成配对信息”，显示一次性配对二维码。
6. 鸿蒙 App 打开 **Codex → 创建连接 → 扫描二维码**，扫描电脑上的配对码，确认电脑名称和地址。也可在创建连接页导入电脑端导出的配对文件，或粘贴完整配对信息；“连接保护”中的证书指纹不能填作 token。
7. 选择项目、模型和权限，开始发送任务。首次建议使用“只读分析”，发送“概括项目结构”。

配对信息 5 分钟内有效，成功使用一次即失效。每台手机获得独立的连接凭据，可在“设备与任务”单独撤销。请勿公开配对二维码、内容或文件。

手机默认记住连接，之后在 **Codex → 我的连接** 点击电脑即可重连；支持保存多台电脑，通过连接右侧的菜单可断开当前连接或删除本机保存的凭据。关闭“记住此连接”时仅保留当前会话。创建连接页可直接返回；对话左上角历史菜单中的“我的连接”或手机返回键可回到连接列表，电脑上的任务继续运行。

局域网证书由程序自动生成，不要求域名，也不需要把证书安装进手机系统。手机只为这组连接添加配对证书，仍检查 HTTPS 证书链、有效期和地址。

电脑端 1.1.6 起，点击桌面窗口“×”会询问 **隐藏窗口 / 关闭应用**。选择“隐藏窗口”时，手机连接和任务继续运行，可从托盘重新打开；选择“关闭应用”时，会停止后台服务及其管理的 Codex 进程后退出，独立任务会中断。1.1.7 的官方桌面共享任务由原客户端执行，关闭 ClawMate 只断开观察，不终止原客户端的任务。托盘和“设备与任务”中的“关闭应用”具有相同退出行为。电脑休眠、关机或关闭 ClawMate 后，手机不能继续操作。

若旧版本异常退出留下 `daemon.lock`，新版会核对对应进程的可执行文件和启动时间，自动恢复失效锁，包括进程号被 Windows 分配给其他程序的情况。仍存活的旧 Node 后台或无法核对身份的进程不会被强行结束；无法响应时会显示实际 `daemon.log` 路径，保留配置和配对数据。

## Tailscale 组网

鸿蒙手机可通过卓易通安装 Tailscale，使用微软或 Apple 账号登录，无需翻墙。电脑安装 Tailscale 后，两端选择相同的登录方式并登录同一个账号。在设备列表中确认手机和电脑均在线，即已加入同一个虚拟局域网，设备地址通常以 `100.` 开头。

安装和登录步骤见 [Tailscale 组网教程](../docs/codex/tailscale.md)。

## 通过异地网络连接 ClawMate

手机与电脑已通过 Tailscale 互通时，当前桥接可以继续使用，无需更改手机通信协议：

1. 先在电脑开启 Tailscale，再使用“局域网 · 自动安全配对”模式；监听范围选“允许局域网 / 远程设备访问”。
2. 在“手机配对”的地址列表选择电脑的 Tailscale IPv4 地址，例如 `https://100.101.102.103:8787`（示例地址，端口以实际配置为准），重新生成配对码并在手机扫描。电脑端会把检测到的 IPv4 地址加入配对证书。
3. 确保手机端的 VPN 路由覆盖该地址，Tailscale 访问策略及电脑防火墙允许手机访问对应 TCP 端口，电脑保持在线。

原来的 `192.168.*` 连接不会自动切换到 Tailscale 地址。Windows/macOS 常规安装和 Linux TUN 模式沿用系统网卡发现；Linux 1.1.9 起还支持没有虚拟网卡的用户态 Tailscale。程序只读查询本机 Tailscale socket，检测到在线的本机 IPv4 后优先用于配对，并将地址加入自动证书，不需要改用公网证书或给容器添加 TUN 权限。

Linux 会检查常规 socket 路径及同一用户或 root 的 `tailscaled --socket` 参数，Tailscale CLI 无需在 PATH 上。若 `/proc` 不可读或存在多个实例，可以在启动 ClawMate 前显式选择 socket：

```bash
CLAWMATE_TAILSCALE_SOCKET=/实际路径/tailscaled.sock ./bin/clawmate-codex start
./bin/clawmate-codex status
./bin/clawmate-codex pair --origin https://本机Tailscale地址:8787 --output phone.clawmate-codex-pair.json
```

后台继承启动时的环境变量；更换 socket 时先停止空闲服务并 `quit`，然后用新变量启动。`status` 的 `network.tailscale` 显示发现结果、地址及失败原因；状态缓存最多 5 秒，启动和生成配对时会重新查询。离线或读取失败时不会继续使用缓存的 Tailscale 地址。程序不会替你登录 Tailscale、修改访问策略或启用 Serve/Funnel。用户态入站连接由 Tailscale 转到同一网络环境的 localhost 同端口，因此服务应允许远程设备访问，手机和服务器还需满足 Tailscale 的访问策略。

默认自动证书按 IP 签发；改用 MagicDNS 域名时需要另行配置匹配该域名的 HTTPS 证书。

Tailscale 提供设备之间的网络连接，桥接服务仍需启动并完成配对，参见 [Tailscale 官方连接说明](https://tailscale.com/docs/how-to/connect-to-devices)。此处为代码与配置路径核对，未做手机和电脑的 Tailscale 实机连通测试。

## 终端使用

桌面版包含同样的终端工具。在“终端与启动”点击“安装终端命令”，然后打开新终端。也可直接使用界面显示的终端工具路径。

无桌面的服务器只需下载终端版压缩包，解压后运行其中的 `bin/clawmate-codex`（Windows 为 `.exe`）。保留旁边的 runtime 和 host 文件夹，不要只移动单个可执行文件。

```text
clawmate-codex setup
clawmate-codex login
clawmate-codex start
clawmate-codex pair --output phone.clawmate-codex-pair.json
```

服务器非交互配置可以使用：

```text
clawmate-codex setup --project /完整项目路径 --name 我的开发机
```

查看和维护：

```text
clawmate-codex status
clawmate-codex devices
clawmate-codex revoke 设备ID
clawmate-codex stop
clawmate-codex quit
```

`stop` 拒绝在任务仍执行或等待审批时停服；可以在手机或桌面“最近任务”先停止任务。`quit` 直接退出后台服务，会中断任务。

## 云服务器

“电脑与网络”选择“云服务器 · 已有 HTTPS 证书”，填最终 HTTPS 地址，选择证书完整链和私钥，再保存和启动。终端也可用 `setup --config 配置文件` 导入相同网络设置。公网 DNS、路由和防火墙需要由服务器所有者配置，程序不会创建公共中转或自动开放路由器端口。

普通用户优先使用局域网自动配对。云服务器或跨网络连接需要手机能路由到对应地址；安全配对不能代替网络连通性。

## 应用更新

1.1.13 起，桌面侧栏的“应用更新”可检查 GitHub 上的连接器发布。默认启动 12 秒后检查，此后每 6 小时检查一次；可以关闭自动检查，或选择接收测试版。检查失败会显示错误，不会把网络失败当成“已是最新”。更新操作仅在本机 GUI/CLI 可用，不向手机开放安装接口。

发现新版本后点击“下载更新”。下载支持暂停续传，完成后核对 GitHub 提供的 SHA256 摘要或同一 Release 的 `SHA256SUMS.txt`；缺少校验信息、大小不一致或校验失败都不会安装。

- Windows 桌面：点击“重启并安装”，程序确认没有运行任务后关闭自己的后台，使用原安装目录运行 NSIS 安装器，并重启应用。未签名包仍可能遇到系统提示。
- Linux 桌面/CLI：在安装目录旁解压到新目录，先检查运行版本，再替换原安装；替换失败会恢复原目录。成功后保留一个 `.clawmate-backup-*` 回滚副本，并尝试恢复此前开启的连接服务。安装目录需要当前用户可写；系统目录需下载后由管理员更新。
- macOS：当前包未签名，提供自动检查、下载和打开安装文件；退出旧应用后将新版移入“应用程序”。当前未接入 macOS 原生自动安装，后续签名发行可再接入。

配对证书、设备凭据、项目授权和会话记录保存在独立应用数据目录，更新不会覆盖它们。所有运行、待审批、停止/释放中及状态未确认的任务都会阻止安装；请先完成、停止或重新打开会话确认状态。无需重新配对。

服务器命令：

```bash
clawmate-codex check-update
clawmate-codex update
clawmate-codex update --yes
clawmate-codex update --yes --download-only
clawmate-codex check-update --preview
```

`--preview` 会保存测试版渠道设置。CLI 检查/下载不需要启动连接服务。Linux 自动安装由独立更新进程完成，当前命令退出后仍会继续；结果见应用数据目录 `updates/install-result.json`，详细安装错误见 `updates/install-*/install.log`。安装失败时原目录仍可使用；重新打开应用可看到失败原因。Windows/macOS 的终端压缩包下载后手动替换。

发布方需要创建 `codex-bridge-v<版本号>` Release，并上传对应架构的完整安装包和校验信息，单独 push 代码不会触发更新。`build/release-metadata.mjs <产物目录>` 可汇总当前版本的 `SHA256SUMS.txt`。GitHub Actions 的“Build Codex PC companion”增加可选发布开关；所有架构构建成功后才发布，可单独选择是否标为预发布，已有同名 Release 不覆盖。当前桌面/CLI 共用本地 Release 更新服务，`publish: null` 用于关闭 electron-builder 自身发布，不影响本更新服务；无需另建更新服务器，也不要求用户提供 GitHub token。

### 电脑已有会话与实时共享（电脑端 1.1.7 起）

手机 Codex 左上角菜单 → **电脑会话**，可以分页查看当前电脑已授权项目中的本地历史；点击会话读取对话，点击“查看更早记录”继续加载。刷新按钮用于更新电脑列表。只有选中会话后才读取其正文，浏览不会恢复或运行任务。

保持 **官方 Codex 桌面端和 ClawMate 连接服务同时运行**，在手机“电脑会话”选择桌面已经打开的原会话。兼容时显示“与电脑实时共享当前会话”：手机发送的消息交给原桌面后台，电脑与手机看到同一轮输出，命令/文件审批与补充问题可在任一端处理，停止也作用于同一轮。电脑发起的下一轮会自动同步到手机。执行期间手机保留停止入口，完成后可继续发送；不并行启动第二个执行进程。

新对话和未接入的电脑会话默认“允许工作目录内修改 + 请求批准”。空闲时在右上角设置修改，下一条**手机消息**生效；电脑自行发起的消息遵循电脑设置。手机显式传入权限，不继承桌面的完全访问配置，但桌面自身的运行目录及组织策略仍会参与最终权限计算。特殊 MCP、登录等确认暂时需要在电脑端处理，手机会显示提示。

实时共享使用官方客户端本机的版本化协调通道，目前已对照 Windows Codex **26.1013.4894.0** 的协议并完成只读连接验证。这不是公开稳定 API；协议不兼容会明确报错，不会强制解锁或改写官方程序。断线或快照缺失时暂停转发，结果未确认的消息不自动重发，请先刷新确认。远端主机、云任务及工作目录未授权的会话不接入此通道。

电脑端 **1.1.12** 起，本地无所属项目（projectless）的会话也可接入，前提是它的实际工作目录已经单独授权。例如会话登记在 `new-chat`，即使它能访问另一个代码仓库，也需要授权 `new-chat` 本身。添加目录只需停止连接服务、保存并重新启动，再在手机断开重连并重新打开原会话，不需要重新扫码。旧会话绑定会在空闲时更新，聊天记录与交付文件保留；若正在发送时发现目录变化，本次不下发，需重新打开会话确认新目录后再发送。

1.1.8 修复 1.1.7 手机消息缺少桌面渲染必需的 `text_elements` 数组，导致后台能回答而官方窗口显示“出了点问题”的错误；同时将相邻文本用换行分隔。若已触发，先暂停 1.1.7 手机下发，待当前执行结束后退出并重开官方 Codex，让它从原生持久历史重载，再使用修复版连接服务。修复不改官方安装文件或历史记录。

Linux 终端版 **1.1.10** 起也支持原生 Codex App Server daemon：保持服务器上的原 Codex 终端和 ClawMate 服务同时运行，在手机的“电脑会话”重新打开原条目即可。程序自动寻找同一用户、网络命名空间和 `CODEX_HOME` 下持有该会话的私有 Unix WebSocket，不需要填写后台端口、退出终端或重新配对。已在 **0.163.0** 上验证双向消息、审批、断线重连和停止。关闭 ClawMate 只断开它自己的连接；原后台继续管理任务。暂不接管其他用户、其他容器/网络命名空间、`--no-daemon` 独占 CLI 或任意 TCP App Server。登录、MCP 授权等特殊确认继续在电脑端处理。

没有兼容的在线会话持有者时，仍走 1.1.4 的原 session 接力：每轮独立恢复完整上下文，完成后释放原生写锁。若旧客户端提示“电脑仍持有此会话”，须先由原客户端释放；仅停止生成或切换窗口不一定释放，必要时退出旧客户端后重试。手机新建的独立会话和此前生成的副本保留原执行方式，不会自动合并为官方桌面会话。

列表包含 CLI、VS Code、App Server 等本地来源，排除子智能体、临时及已归档会话；接力过的原会话仍在电脑列表中。只显示会话工作目录与电脑已配置项目**相同**的会话；工作树、子目录或其他项目需要在电脑端另外配置对应项目路径。手机列表最多加载 1000 个会话，正文分批显示，完整模型上下文保留在 Codex 中。

若列表为空，确认桥接与原 Codex 使用同一 OS 用户及同一份 `CODEX_HOME`（未设置时使用该用户默认 Codex 数据目录），并在电脑端配置原会话的实际工作目录。不同系统用户、WSL、远端主机或云端独有历史不会因登录同一账号自动合并。此功能不会搜索、复制其他用户的数据目录。

### 权限与重连提示（电脑端 1.1.5 起）

手机 Codex → 右上角设置 → **批准方式**：

- **请求批准**：在所选范围内工作，越界时向你申请。
- **帮我批准**：由 Codex 自动审核符合条件的申请；保留沙箱，无法自动处理的操作仍可能需要你确认。该能力受账户和组织策略限制，不可用时不会自动切换到完全访问。
- **完全访问控制**：允许操作电脑上该用户可访问的文件与网络，不再通过普通命令审批暂停；需要明确选择，不会默认启用。

前两种方式还可选择“只读分析”或“允许工作目录内修改”。修改在下一条消息生效，执行中、待审批和释放中不能更改。新设置会用于新会话、已有手机会话和电脑接力会话。旧副本仍可独立继续。

Codex 第一次发出可重试错误时，手机聊天顶部固定显示“正在重连 Codex 服务”，有次数信息时显示例如 `2/5`，并显示已等待时间。状态更新使用最长 12 秒的有界等待，收到事件就立即返回；前台下一次等待最短间隔 750 毫秒。无明确重连事件但 8 秒没有新输出时，会先提示电脑仍在执行，避免误判任务已停止。收到新输出、任务结束或停止后更新或清除提示。手机与桥接之间断网会单独提示，重连不重复下发任务。

### 手机接收交付文件（电脑端 1.1.1 起）

Codex 成功完成一轮任务后，手机会接收最终答复中明确链接的成品，支持 PPT/PPTX、PDF、DOC/DOCX、XLS/XLSX、CSV、常见图片、文本和 ZIP 等。生成文件需要工作目录写入权限；可在手机新对话的设置中选择“允许目录内修改”。

请让 Codex 在最终答复给出 `[文件名](项目内文件的绝对路径)`。桥接不会扫描全部文件，不收集工具输出、过程截图和临时目录；项目外文件、软链接及硬链接也不会回传。旧任务的纯文字文件名不会自动补抓，可以继续对话让 Codex 重新提供成品链接。

手机自动分块接收并校验 SHA256，保存到 App `filesDir/codex/sessions/<电脑地址摘要>/<session编号>/artifacts/`，每个文件独立保存原始信息；原始文件不会写进公共图库。文件卡片可“打开”或“另存为”，系统不支持预览的格式仍可导出给其他应用。

每个成品不超过 128 MiB；每轮最多 24 个、每个会话最多 128 个/512 MiB，电脑端留存快照合计最多 2048 个/2 GiB。超过限制或下载失败时手机显示原因和重试入口。断网、离开会话时未完成的临时下载会清理，已保存文件保留。改换电脑地址会使用独立的手机存储命名空间。

仅保存在电脑工作目录中的中间文件不会复制到手机。已交付快照位于电脑配置目录的 `tasks/artifacts/`；它用于保证之后原文件变化不会影响下载，不会在退出任务时自动删除。

配置目录：Windows 为 `%LOCALAPPDATA%\ClawMateCodex`，macOS 为 `~/Library/Application Support/ClawMateCodex`，Linux 为 `~/.config/clawmate-codex`。桌面“终端与启动”也会显示实际位置。

Codex 的登录由官方 Codex 管理，使用当前 OS 用户已有的 Codex 认证存储；安装本程序不会把 OpenAI 凭据同步到手机。项目内工作区沙箱不是读取隔离，不要把包含个人密钥的整个主目录设为项目。需要更强隔离时使用专用 OS 用户或虚拟机。

升级时退出后台服务，再安装新版。1.1.3 起，新界面会核对后台版本和启动器路径；遇到旧安装留下的空闲后台，会正常停止后从当前安装目录重启。有任务或导入操作进行时会提示先完成/停止任务，不会为升级自动中断任务。命令行 `status`、`stop`、`quit` 仍可检查或显式退出旧后台。配置、设备和任务不保存在安装目录，升级会保留它们。软件不会静默下载执行新版本；请使用维护者提供的签名安装包和校验清单。

附件、任务历史与设备权限管理适用 App 的隐私说明；移除手机或卸载桌面程序不会自动删除项目中的附件或 Codex 历史。

## 无法连接时

- PC 应用需要显示“手机连接服务已启动”；手机和 PC 地址必须可互访。
- 配对过期、用过或被撤销后，在 PC 上重新生成配对信息。
- IP 变化后，停止再启动连接服务以更新证书，再生成新地址的配对信息。
- 公网证书需要匹配填写的域名，且完整、有效；程序没有忽略证书错误的选项。
- Linux 桌面版需要系统图形界面组件；纯服务器使用终端版。
- 如果任务需要额外的项目工具，请在 PC 上为项目安装这些工具，而不是给手机安装运行环境。
