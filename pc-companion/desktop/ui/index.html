Codex 账号

使用官方登录，凭据保存在这台电脑。

尚未登录

内置 Codex 运行组件，无需安装 Node.js 或其他命令行工具。

允许访问的项目

手机只能使用你在这里选择的项目文件夹。

请选择具体项目。不要选择包含 SSH 私钥、生产密钥或连接配置的整个用户主目录。

电脑与网络

局域网自动生成独立配对证书，无需域名或修改手机系统信任库。请让手机与电脑处于可互访网络，并允许本应用通过系统防火墙。

把自己的手机配对到这台电脑

先启动连接服务，再生成一次性配对信息。有效期 5 分钟，成功使用一次后立即失效。

在鸿蒙 App 中打开 Codex

  1. 点击“导入电脑配对文件”，选择导出的文件。
  2. 也可复制配对信息并粘贴到手机的 Codex 页面。
  3. 确认电脑名称和地址，完成配对后选择项目开始聊天。

只将配对文件发送给自己的手机。二维码、配对内容和文件均包含一次性秘密，请勿公开分享。

连接保护

手机校验证书和电脑身份，再换取独立设备令牌。每台手机都可以单独撤销，电脑上的 OpenAI 登录不会传给手机。

启动连接后显示电脑证书 SHA-256 指纹

已配对设备

撤销后，该手机下一次请求会被拒绝，其他设备不受影响。

最近任务

关闭桌面窗口后，本机服务和任务继续运行。退出服务会中断任务。

桌面和终端，共用一份配置

终端工具已经随安装程序内置，不需要 npm、Node.js 或源码。

clawmate-codex setup
clawmate-codex login
clawmate-codex start
clawmate-codex pair --output phone.clawmate-codex-pair.json

Linux 安装包会提供系统命令入口；便携版及 macOS 可在此添加当前用户入口。Windows 设置后重新打开终端。

启动与版本

升级时直接安装新版，配置、设备与任务保存在应用数据目录，不会写入安装目录。

正式发行由应用维护者提供签名安装包。Codex、运行时与第三方许可随安装程序一同提供。
